# /infra

Terraform modules for the platform's AWS infrastructure — original work for this project (not
part of the vendored `/app`).

Planned for Phase 1 (see root README and the ADRs): VPC, EKS-equivalent cluster, ECR-equivalent
registry, IAM — developed and iterated against [Floci](https://github.com/floci-io/floci)
locally, validated against real AWS at milestone checkpoints (ADR-0002).

Empty until Floci is set up and Phase 1 starts.
